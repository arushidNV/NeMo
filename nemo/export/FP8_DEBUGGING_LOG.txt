================================================================================

DATE: 2026-01-28

SYMPTOM:
---------
Segmentation fault occurs when ModelOpt tries to quantize the ONNX model to FP8.
The crash happens in libnvonnxparser.so.10 (TensorRT's ONNX parser used internally
by ModelOpt).

ANALYSIS:
---------
1. The crash occurs AFTER ModelOpt detects dynamic inputs
2. ModelOpt internally uses TensorRT's ONNX parser
3. The same ONNX model works fine for FP16 (no quantization needed)
4. The issue is specific to ModelOpt's FP8 quantization process

SUSPECTED CAUSES:
-----------------
1. Dynamic shapes handling bug in ModelOpt
2. Cache-aware model has complex operators ModelOpt can't handle
3. External data file path handling issues
4. ModelOpt version compatibility issue
